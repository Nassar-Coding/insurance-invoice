# Original reference artifacts

The original README, reports, PDFs, CSV and comparison manifest in this directory are historical reference artifacts. They are preserved unchanged, including earlier process/status wording and hashes. They do not describe current repository status. Current documentation is at the repository root and in `docs/` and `reports/`.

`submission.csv`, `reports/metrics.json` and `reports/workload.json` remain the numerical comparison references. `reproduction_baseline.json` retains the pre-cleanup source and result identities. Current documentation fingerprints are recorded separately by `evidence/publishing/baseline.json` without changing the expected numerical or full hospital-result hashes.
