# Historical correction evidence

This directory preserves the original AUD-01/AUD-02 counterexamples and before/after results unchanged. Reports under `before/` describe the pre-correction state. `correction_verification.json` records the actual changes in traces and the unchanged opinions, confidence values, omissions, metrics and CSV. Status fields and process wording are historical, not current repository status.

The implementation summary is [implementation_report.md](../../implementation_report.md). Exact original attempt paths are recoverable from [the history archive](../../../evidence/history/README.md).
