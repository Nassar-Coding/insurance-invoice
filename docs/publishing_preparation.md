## Reproduction boundary

local clone in a new standard-library virtual environment with a small sanitized
environment, removes all reports except required source/candidate review inputs,
all run outputs, historical Git archives and saved reference/correction predictions,
and executes the documented commands. The exact baseline comparison remains in
the parent harness, outside the pipeline. Its preserved execution logs and
comparison results establish what actually passed; original historical pass
records are not treated as new evidence.

PDF rendering uses the separately pinned optional documentation packages. Core
execution/tests install no third-party dependencies. Python 3.12.13 and Git are
needed for the additional clean-clone harness; Git is not imported by pricing.
