# Source review protocol

Apply `prompts/extract_v1.md`, retain raw candidate output and exact input/prompt identities, then apply `prompts/review_v1.md` to every accepted value/predicate and `prompts/map_v1.md` to every mapping group. This acquisition review checks proposed records against source material; it is distinct from independent implementation testing.

Clause ledger states: accepted, unresolved, outside scope. Each has controlling source, generated field/record and affected scope. General definitions and remote dependencies accompany individual rate rows. Missing rules cannot default to no condition. Revisions identify original expectation, actual source evidence, changed artifacts and affected tests.

Source-derived fixtures are reasoned before the interpreter result is observed. They cover threshold equality, prior-only history, cross-invoice context, adjustment rounding/order, dates/precedence, caps/bundles/exclusions and an unchanged-total fault. They are not label-derived. Actual structural/source parity and mapping collision results accompany accepted bundles.
