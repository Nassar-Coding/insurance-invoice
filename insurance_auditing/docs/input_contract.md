# Input contract v1

Use only the named CSV invoice/line columns supplied in README. Missing, duplicate or unknown headers fail the file; harmless column reordering is accepted by name. Malformed CSV quoting is fatal. Ragged rows, missing invoice/line/patient identity, malformed dates, non-integer/non-finite numeric data or supported-range overflow are quarantined with raw fields, source and row identity. No row disappears silently.

Money must be an exact integer with absolute value ≤10^15 cents. Quantities and line numbers use exact integers with absolute value ≤10^9, matching the supplied snapshot. Decimal-quantity support is not advertised. Negative/zero quantities and negative prices are preserved if parseable, then treated as unsupported/erroneous facts by the audit. Admission/discharge may be absent; absent timestamps, episode details and settlement status are never manufactured.

Hospital identity is scoped by the declared source file. Contract/hospital text disagreement is retained for checking. Reused invoice IDs are not multiplied through a join or silently deduplicated. A conflicting corrected-total allocation must lead to abstention. Quarantined relevant facts continue to affect dependency closure; normal audit code has no label-loading path.

AUD-01 correction: typed valid headers and raw patient-ownership evidence are separate. A quarantined header with a recoverable invoice ID retains its patient candidate and source row; an absent patient identifier leaves ownership unbounded. An invalid date or amount does not invalidate a recoverable patient identifier or erase a conflicting one. Patient-specific context uses this complete candidate set; all-patient usage remains independent of patient ownership. Every recoverable header invoice ID receives an opinion or explicit omission, including IDs having no valid typed header. Quality and audit identity counts use that same set. A quarantined header with no recoverable invoice ID cannot be safely assigned to any one invoice: the batch retains its raw occurrence and withholds complete opinions with an explicit unlinked-header reason. It does not guess an identity or date.
